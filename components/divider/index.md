# 属性

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| borderType | 定义线的类型 | `"solid"` \| `"dashed"` \| `"dotted"` \| `"double"` | `"solid"` |
| position | 定义文字位置 | `"left"` \| `"right"` \| `"center"` | `"center"` |
| type | 定义菜单排列方式：垂直，水平 | `"vertical"` \| `"horizontal"` | `"vertical"` |
| theme | 定义菜单主题 | `"light"` \| `"dark"` | `"light"` |
| margin | 定义`Divider`外边距 | `"large"` \| `"default"` \| `"small"` \| `"none"` \| `number` | `"default"` |
