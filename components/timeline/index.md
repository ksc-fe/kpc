# 属性

## TimelineItem

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| type | 轴点颜色类型 | `"primary"` \| `"success"` \| `"danger"` \| `"warning"` | `"primary"` |
| size | 轴点的大小 | `"default"` \| `"large"` \| `"small"` \| `"mini"` | `"default"` |
