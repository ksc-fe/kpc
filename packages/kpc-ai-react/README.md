# `@king-design/ai-react`

> King-Design AI conversation components for React.

## Install

```shell
npm install @king-design/ai-react --save
```

## Usage

```tsx
import React from 'react';
import {Bubble, Sender} from '@king-design/ai-react';

export default function App() {
    return (
        <>
            <Bubble content="你好，我是 AI 助手" />
            <Sender />
        </>
    );
}
```
